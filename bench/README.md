# 语料与评测

## 这 30 句从哪来

**全部来自公开的职场黑话整理**，不是本仓库作者编写的：

- 知乎「职场黑话翻译」类整理（领导潜台词、互联网黑话、会议暗语）
- 面试潜台词讨论（HR 话术、婉拒客套话）

**每一句的 `source_meaning` 是该网页给出的释义**，同样不是我写的。

## ⚠️ 但有一处是主观的，必须说清

**把这 30 句的释义映射到六类分类学，是我做的。**

原始网页给的是自然语言解释（比如「就是针对你」），我要把它归到 `reversed` / `declined` / … 里的某一类，
**这一步是人工判断，带有主观性**。

所以 `run.py` 报出的数字要这样读：

- **分布**（哪一类多、哪一类空）是**客观**的——不依赖我的映射
- **「对/错」**是**有主观成分**的——它衡量的是「模型的答案 vs 我的归类」

## 怎么跑

```bash
set -a; . ./.env; set +a
python3 bench/run.py
```

输出三部分：六类分布 / 确定度分布（三档）/ 逐条对照（模型读作 vs 网页给的意思）。
